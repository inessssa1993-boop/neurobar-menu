# Меню Нейробара

Отдельная страница-меню для второго планшета: четыре коктейля с картинкой, названием и составом, в том же стиле, что и основной сервис «Нейробар».

## Что где
- `index.html` — страница; `assets/menu.js` — **тексты меню** (названия, составы, подпись внизу); `assets/style.css` — вид.
- `assets/cocktails/*.webp` — картинки бокалов, `assets/fonts` — шрифты, `assets/bg.jpg` — фон.
- `sw.js`, `manifest.json` — офлайн-режим и «установка на экран Домой».

## Как поменять состав или подпись
Откройте `assets/menu.js`, поправьте нужные строки (`name`, `alt`, `ingredients`, `footer`), сохраните/загрузите заново.

## Как открыть на втором планшете
1. Выложить папку на хостинг с HTTPS (например GitHub Pages), открыть адрес на планшете (с интернетом).
2. Safari: «Поделиться → На экран Домой» (Android Chrome: «Установить приложение»), запускать с иконки.
3. Автоблокировка экрана: «Никогда», подключить зарядку; на iPad включить Гид-доступ (как в инструкции основного сервиса).
4. После первой загрузки меню работает без интернета.

## Проверка на компьютере
`serve.bat` (нужен Node.js) → http://localhost:8778

Экран подстраивается: планшет горизонтально (4 колонки), планшет вертикально (2×2), телефон (прокручиваемый список).
